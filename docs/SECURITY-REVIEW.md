# Security regression evidence

This is an internal engineering review and automated regression suite, not an independent audit. It covers the browser challenge, native command parser, native delivery envelope framing, keeper cancellation state, and optional local delivery relay.

## What the added checks establish

| Boundary | Executed check |
|---|---|
| Signed memo parser | 2,048 generated arbitrary byte inputs with arbitrary network bytes; no parser panic |
| Memo integrity | 2,048 sampled single-bit mutations of signed commands rejected |
| Integer encoding | 2,048 generated valid POSTPONE sequence/expiry round trips |
| Ciphertext parsers | 2,048 generated byte inputs passed to both package/envelope parsers without panic |
| Envelope framing | 2,048 bounded ciphertext round trips and 2,048 trailing-byte rejection cases |
| Cancellation | 64 generated combinations of on-time cancellation height and later sequence/expiry; cancellation stays terminal with no delivery |
| Recipient access | Existing crypto tests reject wrong keys, tampered ciphertext, duplicate shares, invalid context and fewer than three shares |
| Network mailbox | HTTP auth, mailbox isolation, read/write capability separation, conflicting retry, restart, bounds, and injected persistence failure |
| Browser challenge | Actual two-share failure, wrong-key failure on the same vault, valid recovery/download, stale-scan and cancellation policy outcomes |

Property inputs are generated per run. These counts are configured cases per property, not exhaustive coverage or a security guarantee. The browser timing and keeper records are simulated; native testnet evidence remains separately linked in the Judge Proof page.

## Reproduce

```sh
npm ci --legacy-peer-deps
npm test
npm run typecheck
cargo +1.99.0 test --locked --manifest-path backend/Cargo.toml
```

The network-delivery rehearsal and its verified scope are described in [REHEARSAL.md](REHEARSAL.md).

## External review still required

An outside reviewer should inspect cryptographic composition and commitment binding, shared-scanner trust, cancellation races, crash/reorg handling, key backup and recipient provisioning, and relay denial of service. No external reviewer or independent audit is claimed by these changes. The relay transports encrypted shares; package distribution and recipient key custody remain separate operational responsibilities.
